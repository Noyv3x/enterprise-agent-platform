## What was changed

- Rewritten as a compact SKILL.md; RED-GREEN-REFACTOR and the verify-red/verify-green steps are retained.
- `references/writing-good-tests.md` condenses upstream `writing-good-tests.md`.
- The upstream instruction to delete implementation written before tests and start over was deliberately **not** adopted: this platform preserves existing and user-written work and uses characterization tests instead.
- Added for this platform: preservation rules, proportional use, and parent-owned verification when subagents help.
