# Citation guide

## Verify before listing a reference
1. **Opened:** you read the page or abstract in this run (record the date accessed).
2. **Identity:** title, authors, year, publisher/journal match across at least two places (the page, the DOI/Crossref record, the search result).
3. **Support:** the sentence you cite is actually stated by the source (quote it in the ledger). A registered DOI proves the record exists, not that it supports the claim.
4. **Status:** corrections, retractions, superseded versions (arXiv vN, standard replaced).
5. **Link:** URL stable and opens; DOI preferred when present.

## Evidence grades
| Grade | Meaning | Example |
|---|---|---|
| A | primary or rigorous, method visible | statute text, statistical bulletin, peer-reviewed study, filing |
| B | credible secondary, sourced | review article, quality news with named data source |
| C | weak/unsourced/vendor | white paper without method, blog |
Conclusion confidence 高: ≥2 independent A/B sources agree; 中: one A/B or conflicting sources explained; 低: only C or inference.

## GB/T 7714-2015 patterns (default for Chinese reports; check against the current standard when strictness matters)
- 期刊: `作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.`
- 专著: `作者. 书名[M]. 版次. 出版地: 出版者, 出版年: 页码.`
- 学位论文: `作者. 题名[D]. 保存地: 保存单位, 年份.`
- 标准: `起草者. 标准号 标准名称[S]. 出版地: 出版者, 年.`
- 电子资源: `作者. 题名[EB/OL]. (发布日期)[引用日期]. URL.`
- 析出文献/报告/专利: `[C]` 会议, `[R]` 报告, `[P]` 专利, `[N]` 报纸。
Three authors then 等 (中文) / et al. (English); in-text numbered `[1]` in order of first appearance (顺序编码制).

## APA 7 (English default)
`Author, A. A., & Author, B. B. (Year). Title of article. Journal, volume(issue), pages. https://doi.org/…`
Web page: `Organization. (Year, Month Day). Title. Site. URL`. Preprint: add the repository name and version.

## Reporting what you could not do
List unopened sources, paywalled items (abstract only), unverifiable claims, and searches that returned nothing. A report that hides gaps is worse than a short one.
