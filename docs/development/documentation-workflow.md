# 文档与代码同步流程

`docs/` 定义意图和契约，代码／测试实现和验证；[domains.json](../domains.json) 登记所有权／生成关系。根 AGENTS／README 只作规则和导航，不维护第二份规范。

## 修改顺序

1. 明确交付物、非目标、影响所有者和验证方式。
2. **行为或契约改变才 doc-first**：接口、配置、持久格式先改规范；跨语言／稳定精确值先改机器契约，再生成消费者、同步实现／行为测试。
3. 恢复既有契约的修复、重构、测试、文档维护可独立交付，不制造文档共改。
4. 检查当前树并完成[交付门禁](testing.md)；评审逐一核对真实受影响契约，映射不代替语义／跨组件评审。

## 命令

仓库根：

```sh
python3 scripts/docs_sync.py sync
python3 scripts/docs_sync.py check
```

`sync` 只写登记的确定性生成文件，无生成目标的契约仍校验。不得手改消费者、拿哈希收据证明实现，或为内部调优值另造配置真源。

`check` 验证当前磁盘树：

- 覆盖、所有权和文档／代码／测试分类有效，登记路径／模式有真实消费者。
- 闭世界 schema、类型、边界、必需消费者及全部生成字节一致；共享整数／换算符合 JavaScript 安全范围，Node timer 可执行。
- manifest、源、目标不逃仓库／symlink；目标为普通非可执行文件，不锁死单一权限模式。
- Markdown 本地目标存在；**不验证标题锚点、自然语言或行为**。

镜像容量键须与当前镜像集合相等，生成同一 Python／TypeScript／Go 只读目录。生产值只归 canonical JSON，测试验结构／边界／消费安全，不复制默认值。

## 边界

CI 对候选 checkout 跑同一 check；它不认证编辑顺序、Git 历史、语义或暂存／工作树一致，没有共改门禁、豁免标记或 INDEX/WORKTREE 快照认证。交付者确认提交范围；affected 的[代码影响选择](testing.md)独立于文档检查。

发布协议归[自动更新](../operations/auto-update.md)，真实验收归[测试与验证](testing.md)，上游／运行数据边界归[仓库指南](repository.md)。静态不代证实际行为；共享门禁用明确提供的基础工具，不因缺可选搜索工具跳过安全检查。
