# 产品设计

本文定义产品边界；组件与数据流见[系统架构](system-architecture.md)。

## 产品目标

平台为彼此可信的小规模内部成员提供个人 AI 和公共频道 Agent。“公共”指具备工作区读取权限的平台成员可见，不是匿名互联网公开；发送仍需聊天权限。

每个主 Agent 独享工作区、会话、记忆、Skill/MCP、浏览器状态和 Sandbox；委派共享父环境。Sandbox 减少污染和误操作，**不是恶意多租户安全边界**。显式宿主执行可获得部署用户及免密 sudo 权限，接受此风险是部署前提，见[安全设计](security-and-trust.md)。

## 角色与权限

仅服务端权限构成授权。账号保存姓名、职位、模型、思考深度、时区、启用状态；权限组不作姓名副标题。

| 权限组 | 职责／能力 |
| --- | --- |
| 管理员 | 账号、模型授权、运行时、更新、Telegram、审计与系统设置 |
| 经理 | 管理公共频道，使用个人 AI 和频道 Agent |
| 成员 | 参与公共频道，使用个人 AI |
| 只读 | 读取公共频道，不能发送 |

## 核心能力

- **对话与文件**：公共／个人对话、附件、短输入合并、流式回复、上下文用量；本地 `/compact` 不进入产品消息或模型。Agent 处理文件、命令和网页，交付经结构、内容、视觉检查的真实文档，不用 Markdown 冒充文件或机械默认样式。XLSX、DOCX、PPTX、PDF 同源只读预览，其它附件下载。
- **知识与扩展**：自动记忆、用户资料记忆、跨会话搜索、私人回复后的低优先级学习复盘；独立工作区 Skill/MCP 按调用重读，无需重启。保留只读预置技能、用户技能及仅自动维护 Agent 自建技能的闭环；外部服务按其安装说明自行接入。
- **计划与通信**：个人 AI 的一次性、间隔、cron 任务，IMAP/SMTP 邮箱及有积压上限、有界预览、可恢复去重的收信唤醒；Telegram 仅私聊；回复完成系统通知。
- **工作可见性**：工具调用产生工作记录；当前聊天的电脑画面展示真实文件、终端、浏览器、搜索或 HTML，默认只读，浏览器接管须另一次明确手势。
- **运营**：Codex/Grok OAuth，不提供模型 API key 产品入口；账号、频道、消息与 token 用量管理；可信局域网入口默认关闭；Sandbox 停止重建保留工作目录、HOME 和环境；自动更新等待空闲、阻断使用、失败回滚。

细则见[集成](integrations.md)、[数据](data-memory-sessions.md)、[前端](frontend.md)、[更新](../operations/auto-update.md)。

## 对话模型

主 Agent 身份与工作区长期稳定，会话可轮换。登录默认个人 AI，无权限才回退首个可读频道；频道须显式导航，持续标明成员可见。

个人消息按进入顺序持久化，合并仍保留每条处理状态；产品历史以平台消息库为准。Platform 将文件交付标记转成结构化附件，界面不解析正文路径。撤回本人已持久化频道消息只改变可见性，不取消回复或删除 Runtime 历史、附件、审计。

管理员和经理可删除公共频道：从产品中移除访问并停止频道工作，保留历史、附件、Agent 工作区和会话；不等于永久数据擦除，不提供恢复入口，已占用名称仍保留。权限和清理失败后的重试见[数据与会话](data-memory-sessions.md#产品消息与-runtime-会话)。

私人和频道提示词均携带可用的用户姓名、职位、当前说话人上下文。Agent 使用配置的展示名称，默认自称 `Agent`，不提 Pi、Runtime、模型供应商、源码维护方或内部实现。默认用用户当前语言和大白话：结果在先、短句，不用套话、官话、无意义标题或重复；用户明确要求的语气与格式优先。

## 品牌配置

默认产品名 `Agent Platform`、Agent 名 `Agent`、组件库默认主色且无 Logo。管理员可热改名称、主色和单一 Logo，全局生效；它们是已验证的展示数据，不产生身份、权限或指令。公开投影／同源 Logo 见[前端品牌契约](frontend.md#品牌与部署定制)。Manager 离线维护页保持中性，不复制品牌配置。

**品牌不改变技术身份**：二进制／unit、配置／数据根、Compose／网络／容器及 ownership label、环境变量、secret mount、Cookie、内部 API、数据库 marker、workspace/session identity、包名、release asset 均不从品牌派生。精确身份见[数据布局](../reference/data-layout.md)。源码仓库、Python distribution/module、Go module/import 是开发坐标，无状态重命名须与持久协议分开评估。

## 界面范围

界面以长期阅读和操作为目标，保留说明、权限与错误反馈，不用宣传或装饰大标题。使用完整可用视口；简体中文、English、繁體中文仅覆盖界面，不翻译消息、文件、工具结果或日志。用词、引导、布局与无障碍见[前端设计](frontend.md)。

## 明确不做

- 不承诺“电脑”是独立操作系统、应用导航分区、加密磁盘或不可达宿主／sudo／内网的隔离舱；不提供通用桌面／窗口管理、会话回放、持久电脑主页或交互 PTY。
- 不内置 Sylver Lining 等专用连接器，不把记忆、Skill、MCP、计划、邮件或 `/compact` 包装成操作系统功能；Pi／Firecrawl 上游修改边界见[集成](integrations.md)。
- 只读预览不授予执行权，接管不越过用户、scope、tab 授权；未提交草稿不是持久事实。OAuth 在线发现不绕过 Runtime 能力目录。
