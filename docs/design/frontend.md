# 前端设计

本文只写浏览器端用户能观察到的行为和必须守住的规则。组件怎么拆、样式怎么写、动画参数是多少，以代码为准，不在这里重复。

相关文档：能力范围见[产品](product.md)，系统边界见[架构](system-architecture.md)，信任边界见[安全](security-and-trust.md)，持久状态见[数据](data-memory-sessions.md)，Runtime 协议见[API](../reference/runtime-api.md)。

## 技术与发布边界

- 技术栈：React、TypeScript、Vite。基础控件（表单、选择器、弹窗、抽屉、提示）用 Ant Design；AI 交互界面采用 Beautiful UI 组件（见下文）；样式用 Tailwind CSS 与项目设计 Token。
- `frontend/` 是源码。`enterprise_agent_platform/static/` 是构建产物，不进 Git，容器构建时整体覆盖。
- 发布静态资源时先写入新文件、全部校验通过后才切换入口，再清理旧资源；不保留跨版本兼容层。
- 未登录页、恢复页和维护页不加载聊天、电脑、浏览器或终端代码；登录确认后再按需加载主界面。
- 前端类型随当前 API 一起修改，不保留旧别名。

## 品牌与部署定制

- 未配置品牌时，一律显示中性默认值：名称 `Agent Platform`、助手名 `Agent`、纯文字标识、中性配色和内置图标。任何地方都不能回退到写死的部署方品牌。
- 登录、恢复、维护、错误页、侧栏、页面标题和通知共用同一份品牌，修改后无需刷新即可生效。
- 字段和校验规则见[配置 · 品牌](../reference/configuration.md#品牌)。前端即时提示，最终以服务端为准。
- 公开的品牌信息只有：名称、主色、同源且带版本的 Logo 地址、revision。不包含其它设置，也不加载远程图片。
- Logo 按比例完整显示，加载失败时显示文字名称。技术标识（存储 key、事件名、下载文件名）保持中性，不随品牌变化。

**缓存与并发规则**（防止旧数据覆盖新数据）：

- 登录前可先显示本地缓存的品牌，同时后台重新获取；没有缓存就用中性默认值；网络失败时继续用有效缓存，不阻塞登录。
- revision 只增不减；只有在请求发出后本地状态没变过时，才接受服务端回滚到较低 revision。
- 返回的数据必须先通过完整校验。非法数据会清掉缓存并回到中性值，但迟到的非法响应不能清掉更新的状态。
- 多个标签页之间通过重新请求同步，不直接采用其它标签页写入的值；只有最新发出的请求可以生效。

## 组件与视觉系统

### 设计原则

- 这是企业内部工作界面：不用宣传语、装饰性大标题或大片留白。
- 每页一个功能标题。说明文字只讲用法、权限、限制和真实状态。
- 同一种状态全站只有一种表达：
  - 细环表示正在进行；
  - 勾表示完成，警告标记表示失败；
  - 加载状态用像素网格动画加真实标签；
  - 分类标记（如"公共"）用图标，不用状态点。
- 权限、风险、引导、错误提示和危险操作确认不能为了简洁而删掉。保存按钮留在所属表单内。

### Beautiful UI

[Beautiful UI](https://www.beautifului.dev/)（MIT）是全站唯一的视觉语言。源码、改编说明和许可在 `frontend/src/components/ui/beautiful/`，许可文件随 `public/licenses/` 分发。

- 以下界面采用其源码的生产化改编：工作过程、等待状态、输入框、代码块、审批卡、侧栏、分区标签、资源列表与状态标签、消息操作按钮和流式光标。
- 改编后的组件只接收真实状态、本地化文案和回调，不包含演示数据、定时脚本、远程图片或付费图标。
- 应用布局：侧栏在页面底色上，工作区是一块浮起的圆角面板；窄屏时工作区铺满。
- 管理页、设置和面板里的通用元素也使用 Beautiful UI 的样式：墨色主按钮、柔和底色的危险按钮、墨色开关、胶囊分段控件、安静的提示卡、居中的空状态、统计卡片。输入框和按钮分开放，不拼接在一起。
- 面板（抽屉）内的页面标题由面板标题代替，不重复显示。
- Beautiful UI 没有的交互控件（表单校验、选择器、弹窗、抽屉、表格、上传）继续用 Ant Design 提供行为，外观通过主题设计值对齐；不复制 Ant 内部结构，也不用高优先级样式硬覆盖。
- 共享组件不直接调用 API，也不自造数据。

### 排版、颜色与可访问性底线

- 字体：随静态资源分发 Inter 和 JetBrains Mono 的拉丁字符部分，不请求第三方字体；中文、中文标点和其它字符使用系统字体。等宽字体只用于代码、命令、时间和标识。
- 颜色：使用 Beautiful UI 的中性冷灰语义色，浅色、深色两套。主操作按钮和开关的开启态是墨色；品牌色用于发送按钮、链接、焦点和少量强调；导航选中态为中性灰。
- 对比度：所有文字在其所在底色上至少 4.5:1，包括品牌色文字和状态色。状态不能只靠颜色区分。
- 触屏和窄屏上所有可点区域至少 44px。
- 系统开启高对比度（强制颜色）模式时，依靠阴影区分的表面要补上实线边框。
- 按钮文案按原样显示，不在中文字之间插入空格。

### 动效与阅读连续性

- 动效只用来说明位置和状态变化，不做装饰性入场、弹跳或主题渐变。切换主题时颜色直接切换。
- 内容在提交后变高时（展开工作过程、延迟排版、画中画留白），停在底部的读者继续跟随最新内容；正在往上翻的读者保持当前位置，也不增加未读数。
- 切换对话、加载更早的历史、流式输出都立即收敛，不制造额外的滚动动画。
- 工作过程运行中只有标题文字的微光和步骤细环的旋转，不做多行持续动画。
- "减少动态效果"设置实时生效，不能因此刷新状态、丢失输入或关闭面板。

## 应用外壳

- 语言设置在最外层；品牌在主题、维护页和错误边界之外；更新维护门在登录和业务数据之外。
- 错误边界可以安全地重新加载。客户端路由不是权限边界，权限以服务端为准。
- 窄屏时导航收进抽屉，关闭后焦点回到打开它的按钮；抽屉里保留账号、语言、主题和有权限的操作。

### 登录

- 登录失败时不透露账号是否存在。被限流时按服务端给出的等待时间倒计时，不会自动重新提交密码。
- 登录后一次性取得用户、频道、消息和 Agent 状态。默认进入个人 AI；只有服务端确认用户没有个人 AI 权限，才进入第一个可读频道。
- 登录前、恢复缓存时或失败回退时，不能短暂选中某个频道或覆盖个人 AI 的内容。

### 用语与首次引导

- 固定用语：公共频道 / Public channels / 公共頻道；个人 AI / Personal AI / 個人 AI。内部标识不随用语改变。
- 公共频道在窄屏上也要明确标出"成员可见"。
- 个人 AI 使用指南在以下条件全部满足时，每次登录自动显示一次：历史已加载完成、没有加载中或错误、对话里没有消息、Agent 空闲。侧栏始终保留指南入口。
- 指南里的"试试"只在输入框文字和附件都为空时填入示例并聚焦输入框，不会自动发送，也不会覆盖已有草稿。

## 状态与数据访问

核心规则：**异步操作返回时，必须确认账号和对话仍然是发起时的那个，否则丢弃结果。**

| 场景 | 规则 |
| --- | --- |
| 请求 | 所有请求带同源 Cookie。收到 401 视为会话失效，收到维护响应时显示更新维护页。切换账号时取消旧请求，迟到的结果一律丢弃；切换对话时，旧对话的加载结果也不能写入新对话。 |
| 发送 | 发送前记下当前账号和对话，等待（例如等浏览器接管释放）之后、真正发出请求之前再核对一次。账号变了就丢弃这条消息，不能带到新账号；只是换了对话，就把它放回原对话的"发送失败"队列，不覆盖新对话的草稿。 |
| 上传 | 上传没有固定超时，可以被取消、登出、切换账号、系统更新或配额中断。进度到 100% 后显示"处理中"，服务端保存并入队才算发送成功。完成、出错、取消走同一个收尾流程。 |
| 审计 | 切换查看对象时立即清掉旧对象的消息；只有针对当前对象的最新请求可以写入结果。删除后的刷新不会重新选回已删除的对象。 |
| 模型列表 | 只显示 OAuth 授权范围内的模型，第一项标为推荐。未授权或没有成功获取目录时不显示候选。刷新不覆盖用户已做的选择；"自动"显示当前推荐的模型。 |

- 名字、职位等用户可改的文字都按不可信数据显示；前端的长度校验不是提示词安全措施。
- 从通知或其它入口跳转到对话，一律走正式导航流程。

## 实时对话

### 历史与同步

- 以对话的实时推送（SSE）为主，轮询只用于断线恢复。
- 自己刚发的消息先乐观显示，服务端确认后按稳定顺序合并，不重复、不跳动。
- 加载更早的历史时保持当前阅读位置、不增加未读；不因条数上限裁掉已加载的历史。
- 清空、隐藏、切换对话或服务端重置历史（reset_revision 变化）后，旧的加载请求不能再写入结果。
- 回到之前看过的对话时，先立即显示缓存内容，再从缓存的位置向后补新消息，不用最新一页覆盖已加载的旧页。
- 实时连接断开且服务端暂时不可用时，在对话和账号仍有效的前提下有限次退避重连；切换对话、离开页面、维护或登录失效时停止重连，不产生重复连接。

### 消息显示

- AI 回复没有气泡；用户消息为靠右的灰色气泡，宽度随内容，桌面最宽约 85%。
- 个人 AI 里双方都不显示名字；频道里显示发送者名称。用户副标题只用职位或 `@用户名`，不用权限组充当。
- 每条消息下方有固定的一行：时间（发送或生成中时显示进行状态）加复制、撤回按钮。实时、刚结束和已保存三种状态下这一行位置不变，不跳动。
- 鼠标设备上操作按钮在悬停或键盘聚焦时出现（位置预留）；触屏上常显。复制结果会被读屏软件播报。
- 流式输出时，只在已经收到的文字末尾显示一个细光标，不虚构文字。

### Markdown

- 支持 GFM（表格、任务清单等）、`$...$` 行内公式、独占一行的 `$$` 块公式，以及 `\$` 表示美元符号本身。
- 公式按需加载渲染，禁用可执行命令；公式有误或流式输出中尚未闭合时显示源码，不能让整条消息崩溃。
- 不渲染原始 HTML、不加载远程图片、不打开不安全链接。
- 代码块显示语言、行号和复制按钮；长代码、宽表格、长公式在自身内部滚动，不撑宽页面。

### 审批与撤回

- 审批请求带上用户看到的 run_id、approval_id 和选择。服务端返回 409（审批已变化）时刷新并重新显示，不能把用户的选择套用到新的审批上。
- 审批卡显示标题、说明、完整命令，以及四个选项：允许一次（主操作，最小授权）、本会话允许、始终允许、拒绝（危险样式）。提交中全部禁用。
- MCP 工具同样逐次审批，不显示配置里的环境变量值。
- 频道里只能撤回自己已保存的消息。撤回需要确认、防重复提交；成功后从列表和缓存移除，失败则保留并提示。撤回不会取消正在进行的 AI 任务，也不会清理模型上下文。

### `/compact` 命令

- 在输入框输入 `/` 会出现命令建议，目前只有无参数的 `/compact`。
- AI 空闲时执行：由平台请求 Runtime 压缩当前会话，并用本地化提示说明是否省略了历史。它不会产生用户消息、AI 任务，也不会把命令文字发给模型。
- 带附件、带参数，或 AI 正在排队/工作时，拒绝执行并保留草稿。其它以 `/` 开头的文字按普通消息发送。

### 工作过程

工作过程展示 AI 实际调用了哪些工具，只根据真实的工具事件建立。学习复盘（`learning.review.*`）不在聊天中产生任何显示或通知。

**标题行**

- 运行中默认展开，标题为"正在处理 / Working / 正在處理"；等待审批时为"等待审批 / Awaiting approval / 等待核准"并换成锁形标记。包含对象的完整状态说明放在描述和 tooltip 里。
- 运行中和纯等待状态显示从开始起的已用时（`MM:SS`）；历史记录不计时。
- 用户可以把运行中的过程收起成一行：当前任务、摘要、步数和已用时。这个选择在本次任务内保持，后续更新不会自动展开或收起。
- 任务结束时只自动收起一次，从运行状态过渡到已保存记录时不会闪现展开的内容。
- 历史记录的标题是真实的操作分类计数（如"1 个文件操作 · 2 次搜索"）。整体失败时显示"AI 工作过程失败"；整体完成但有失败步骤时显示警告标记和"N 步失败"。
- 还没有调用工具时，只显示等待动画和真实状态文字（排队、回复中、等待审批）。

**步骤行**

- 步骤按首次出现的顺序排列，之后原位更新，不按完成时间重排。最终回复正文不放进工作过程。
- 每行一个标记：运行中为细环，失败为警告，完成后为文件/终端/搜索/浏览器等类别图标。每行显示工具名和一行摘要；路径、命令、查询用等宽字体并单行截断。重复、匿名和内部噪声步骤合并或隐藏。
- 已完成或失败、且有真实内容的步骤可以展开查看：命令、输出或错误、参数、时间。运行中的步骤不能展开。MCP 只显示服务名和工具名，不显示环境变量或已省略的外部结果。
- 参数和结果遵守[数据投影](data-memory-sessions.md)的脱敏和正文排除规则。内容超过上限时在原位注明截断了多少，不能悄悄只保留末尾。

**任务结束后的衔接**

- AI 完成到已保存消息到达之间，原位保留这次任务的最后真实快照（收起的过程和已收到的正文），不出现空白或空状态。保存的消息到达、出现错误记录、切换对话，或约 15 秒后释放；不补造内容。
- 焦点在工作过程里时，自动收起会把焦点移回标题；运行中的记录被已保存记录替换时，焦点交给同一次任务的新标题。用户已经把焦点放在别处（例如输入框）时不抢焦点。

**需要复核（needs_review）**

- 显示最后一条真实说明、阻塞原因和真实的工作过程，不用成功样式，不发完成通知，也不从其中的文字里提取附件。

### 上下文用量

- 输入框发送按钮旁显示"上下文 N%"，点击打开非模态的详情（已用量和上限，带千分位）；Escape 关闭并回到按钮。
- 只显示最近一次已完成回复的占用；没有数据时不显示。不混入供应商或 Runtime 的诊断信息。

### 附件与预览

- 附件只来自消息的 attachments 字段，不从正文或工作过程里的文字解析。
- 附件卡片显示名称、类型、大小和下载按钮。HTML 附件在聊天里只能下载，但可以在"AI 的电脑"中呈现。
- XLSX、DOCX、PPTX、PDF 卡片可展开预览：分别显示工作表、段落、按顺序的幻灯片文字、PDF 已有的文字层。首屏有长度上限，展开弹窗复用同一次预览结果。
- 预览只显示服务端提取的文字，不执行宏、不让浏览器解析原文件，也不引入额外的渲染库。
- PPTX 严格按演示文稿内部声明的顺序显示；关系缺失或不安全时明确报错，不按文件名猜顺序。
- 加载中、无内容、已截断和失败都有明确状态；预览失败不影响下载原文件。格式校验和下载安全见[安全 · 文件与附件](security-and-trust.md#文件与附件)。

## 电脑画面

"AI 的电脑"让用户观察 AI 正在操作的文件、终端、浏览器、搜索结果和网页呈现。

- 它不是操作系统、文件管理器、回放工具或交互式终端；打开观察不会创建任何资源，也不新增 Runtime 工具。
- 同一对话只有一个电脑画面，浏览器和终端共用这一个入口。记忆（个人）、技能、定时任务是独立面板。

固定三语用语（个人 AI 和频道通用，不借用"工作区""沙箱""宿主"等内部词）：

| 用途 | zh-CN | en | zh-TW |
| --- | --- | --- | --- |
| 区域标题 | AI 的电脑 | AI computer | AI 的電腦 |
| 打开/展开的提示与可访问名称 | 显示 AI 的电脑 | Show the AI computer | 顯示 AI 的電腦 |
| 画中画隐藏按钮 | 隐藏 AI 的电脑 | Hide the AI computer | 隱藏 AI 的電腦 |

### 画中画与展开

**画中画（默认）**

- 16:9 小窗浮在阅读区右下、输入框上方，不占页面布局高度；空白处可以点穿和滚动。
- 画中画存在时，对话末尾自动增加同等高度的留白，最新消息总能滚到它上方，不会被挡住。
- "回到最新"按钮居中，画中画靠右，两者不重叠。窗口很矮、输入很长或页面缩放时也不能挤掉阅读区。
- 真实画面铺满小窗；名称、状态、计时和展开标识是半透明的小叠层。整张小窗可以用键盘展开。只有当前任务在计时，历史画面不继续计时。

**何时自动出现**

- 只有当前对话里 AI 真正开始工作（回复中或等待审批）时才自动出现。排队、历史消息、空闲资源或状态刷新都不会让它出现。
- 工作结束后保留这轮最后展示的画面并停止计时；资源已不可读时明确显示已结束或不可用，不假装还在运行。
- 用户点"隐藏"后，本轮后续的任何更新（工具、审批、结束、排队、刷新）都不会让它重新出现；只有下一次 AI 真正开始工作才会再出现。刚开始工作时还没拿到任务 ID，之后补齐的不算"下一次"。隐藏后焦点回到输入框。
- 页头的手动入口与自动显隐互不影响。切换对话或账号时清除保留的画面和隐藏状态。

**展开**

- 固定占据视口右侧一半、全部可用高度，任何窗口宽度和缩放下都一样，没有全屏模式。聊天留在左侧，两边各自滚动。
- 展开后的电脑是非模态区域：没有遮罩、不锁焦点。只有在电脑区域内、且没被子控件处理的 Escape 才收起它；关闭后焦点回到触发按钮，找不到就回输入框。
- 打开对话时电脑默认收起，推送不会自动放大。展开状态保持到用户收起或离开对话。窗口缩放不会重新加载画面或重新申请浏览器控制。
- 打开记忆、技能或定时任务面板时收起电脑，并释放浏览器接管。
- 同一时刻只有一个画面在读取数据：展开时停止画中画的读取，收起时停止展开区的读取。

### 屏幕模式

电脑只显示 Agent 状态里最新可见的电脑类工具，同一任务切换时在同一屏幕里切换，不开多个窗口，也不从日志、正文或路径里猜测内容。

| 模式 | 显示内容 |
| --- | --- |
| 文件 | 读、写、修改文件时显示文件内容，只读。只能读当前工作区内的相对路径，内容有长度上限并标注截断。宿主机目标只显示脱敏路径和状态，不读取正文。 |
| 终端 | 按当前任务和仍在运行的遗留进程分组；遗留进程标为"需关注、仍占用"，不能算作完成或被隐藏。深色终端画布先显示 `$` 和完整脱敏命令，再显示有长度上限的真实输出，用户没往上翻时自动跟随末尾。命令比预览先结束时，用对应步骤的结果补齐输出和结束状态。不支持输入，也不模拟终端控制序列。 |
| 浏览器 | 只在已有标签页或浏览器工具进行中时可用；没有资源时切到其它仍在运行的模式。画面还没到不代表资源不存在，可以先显示骨架。 |
| 搜索 | 网页搜索和文件搜索只显示有长度上限的标题、网址或相对路径和摘要，按纯文本渲染，不变成文件浏览器。 |
| 呈现 | 显示当前工作区里成功写出的 .html/.htm，或本对话最新成功回复里的 HTML 附件。写入尚未完成时先显示骨架，写完后刷新。页面在无同源权限的沙箱 iframe 里运行，脚本无法访问父页面、Cookie 或产品 API。 |

**写作中的草稿**

- 只有 Codex OAuth 模型在写文件时会产生实时草稿。完整写入显示为整份草稿，修改显示为替换片段，都标为"未提交"，不代表已保存、已审批或已执行。
- 实时推送只告诉前端"有新版本"，草稿正文要单独通过授权接口读取；草稿不持久化，详见[数据](data-memory-sessions.md)。
- 前端只追最新版本，同时最多一个在途请求；切换对话、任务、工具调用、路径或进入结束状态后，旧响应不能覆盖新内容。
- 写入开始到文件落盘之间读不到文件属于正常等待，有限次重试。完成或失败后清除草稿，成功时读取同一路径的最终内容。
- 只对真实收到的字符做平滑追赶和变更高亮，不造字符。"减少动态效果"时直接显示最新版本。

### 浏览器接管与发送

- 默认只读。文件、终端、搜索和呈现都不接受远程控制输入。观察不会启动浏览器、创建或切换标签页。
- 观察画面约每两秒刷新一次；接管时按服务端给出的间隔加快，画面静止时逐步放慢，退出接管或页面不可见时恢复低频或停止。

| 阶段 | 规则 |
| --- | --- |
| 接管 | 必须由用户明确点击。先显示服务端已确认的租约（再短也要让用户看到），到期由服务端决定。租约绑定接管时的标签页，不随刷新改变。申请、输入、释放按顺序一个一个发送，不并发。 |
| 操作 | 鼠标、触屏、手写笔统一为左键拖动：按下、移动轨迹、松开作为一次完整动作提交，并显示本地指针反馈。不支持多指缩放、文件选择、剪贴板或任意跳转。 |
| 退出 | 操作结束、指针丢失、失焦、页面隐藏、标签页变化或关闭、租约到期、离开页面或租约冲突时，立即回到只读，丢弃未提交的轨迹，并尽力释放租约。已经开始执行的动作由服务端负责收尾。 |
| 发送消息 | 发送前先回到只读，等所有在途的接管请求和释放完成后再发送；不重复发送，不阻挡下一条草稿，等待前后按[状态与数据访问](#状态与数据访问)的规则核对账号和对话。服务端的隔离规则见[安全](security-and-trust.md)。 |

## 通知与账户集成

**浏览器通知**

- 用户显式开启，由点击操作请求权限。
- 页面已打开、已授权、且页面隐藏或失焦时，任何可访问对话里的新成功回复各通知一次。
- 页面初次加载、加载历史、重复事件、切换对话后的首次加载，或页面正在显示时，都不通知。
- 点击通知会聚焦页面并跳转到对应对话，目标就绪前不显示旧消息。
- 这不是离线推送：关闭页面期间的回复不会补发。非安全连接（非 HTTPS 且非本机）下明确提示不可用。

**局域网访问**

- 默认关闭，可设置独立地址、直连和可信入口网段。只显示平台实际绑定的地址，不修改容器的地址或端口。
- 登录有效期以服务端为准，并说明 Cookie 保存方式和活动续期。明文局域网访问要明确提示 Cookie、同源和通知方面的风险，"已保存"不代表已启用 TLS。

**个人邮箱**

- 提供账户、凭据状态、测试连接、立即检查和收信唤醒。密码不回填，修改其它字段时不清空密码。

**扩展与频道**

- 不提供服务商专用卡片、第二份 MCP 表单或连接商店。Skill 和 MCP 通过对话写入标准工作区；保留技能管理面板。
- 频道名称提示：去掉首尾空格、转小写、空格变连字符后为 2–49 个 ASCII 字符，首字符为字母或数字，其余可包含字母、数字和 `_ . -`。提交用户原始输入，由服务端规范化。

**删除公共频道**

- 管理员和经理可以在侧栏删除公共频道。确认框显示真实频道名，并说明：频道工作会停止、成员失去访问，但历史和文件保留，且没有恢复入口。
- 请求期间防重复提交；失败时保留可重试入口并如实报告清理状态。
- 删除当前频道后，立即清掉它的缓存、草稿、进行中的读取和电脑画面，并跳转到个人 AI、其它可读频道或空状态。其它成员刷新或发现无权访问时同样处理；迟到的响应不能让已删除的频道重新出现。

## 响应式布局

- 页面高度跟随真实可视区域和安全区。聊天区独立滚动，输入框有高度上限，不遮挡最后一条消息，浮动按钮避开输入框。
- 长网址、代码、表格在内部滚动或安全换行，不撑宽页面。除右半屏的电脑外，侧栏不能挤压阅读区。
- 页头操作（记忆、技能、定时任务、Telegram、电脑）为安静的文字按钮，对应面板打开时强调；窄屏（≤800px）只显示图标，名称放在 tooltip。
- 手机上页头标题和操作在同一行，标题单行截断；移动顶栏只有菜单和品牌，不重复页面标题。回车发送的快捷键提示只在鼠标设备宽屏显示。
- 侧栏每个频道一行"# 名称"：成员可见性放在可访问名称里，频道描述放在 tooltip；管理按钮在悬停、聚焦或当前频道时出现，触屏常显。
- 管理和设置页用页内分区标签，不再加第二套固定导航。设置表单宽度有上限（约 720px），时区是可搜索的列表（包含当前值和 UTC）；窄屏时表单单列、按钮换行、宽表格在内部滚动。
- 账户列表显示真实身份、状态、权限和模型，新建和编辑用抽屉。审计页把选中对象的消息和危险操作分开。用量页显示真实汇总，以及按日、账号、对话、模型的表格。
- 底层服务页是只读健康视图，不是启停控制器。只显示名称、是否可用、状态（running、unavailable、available、missing、error、invalid_config）、说明、错误和数据新鲜度，不暴露内部地址、路径或管理来源。

## i18n 与可访问性

- 支持简体中文、英文、繁体中文，默认跟随浏览器语言，用户选择会被记住。新增界面文案必须三种语言齐全。
- 不翻译用户、AI、工具、文件或日志的内容。
- 页面加载前就应用主题，避免闪烁。品牌、深浅主题、触屏、长文和减少动态效果可以同时正常工作。
- 焦点管理：
  - 弹窗和抽屉负责锁定焦点、响应 Escape、处理嵌套和关闭后的焦点恢复。
  - 下拉选择先处理自己的 Escape；嵌套确认只关闭最上层，保留下面的编辑内容和未保存输入。
  - 关闭后焦点回到仍有效的触发按钮或所在界面的合理位置。
  - 电脑画面是非模态的例外。
  - 图标按钮都有可读名称，键盘焦点清晰可见。

## 容器管理状态

- **状态与版本**：显示当前、候选和上一个版本（generation、commit、启用时间），以及健康、下载、状态、阶段和安全的错误信息；回滚后沿用原启用时间。操作时把数值 generation 作为期望版本传给服务端，不能用发布记录里的 ID 代替。未知或不可用的状态不显示为"就绪"。
- **服务目录**：逐项显示 platform、agent-runtime、camofox、searxng、firecrawl-playwright、firecrawl-redis、firecrawl-rabbitmq、firecrawl-postgres、firecrawl-api，Manager 可以并列显示。不能合并必需的依赖。
- **操作**：
  - "检查"只刷新候选版本，不创建操作、不安装也不切换。更新、重启、回滚都通过 Manager 的操作接口，不在前端拼 Docker 或 Git 命令。
  - 预下载和等待任务完成期间不挡其它页面；真正更新时由全局维护页接管。
  - 就绪检查失败时保留旧版本并显示有限的错误说明，不泄露路径、迁移细节、socket、仓库凭据或完整日志；平台可用时显示操作 ID 和宿主机命令行的恢复提示。
  - Manager 不可达时明确显示"控制面不可用"，并禁用所有写操作（保存配置、检查、更新、重启、回滚），不伪装成空闲，也没有备用控制器。
