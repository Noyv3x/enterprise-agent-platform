# 0003：宿主执行逐次审批

- 状态：accepted
- 日期：2026-07-29
- 取代：[0002](0002-docker-manager-and-agent-sandboxes.md) 中的宿主执行审批决定

## 背景

Sandbox 是 Agent 的默认执行环境，普通工具调用应当流畅且无需重复确认。宿主机则承载 Manager、产品数据、Docker 控制面及部署用户能够访问的其它资源；一次宿主调用还可能继承该用户已有的免密 `sudo` 能力。仅记录审计而不在执行前确认，会把模型误判或外部提示词注入直接扩大为宿主副作用。

## 决定

Sandbox 内的 terminal、文件和进程调用在通过确定性安全检查后自动执行。模型只有为当前单次调用明确选择 `target=host` 时才触发用户审批；审批只允许本次通过或拒绝，不能建立会话级、永久或隐式授权。未经批准不得调用宿主执行器，批准结果也不得被后续调用复用。

宿主执行继续以部署用户身份运行，并在执行前记录包含目标、规范化路径、完整普通参数和有效超时的审计事件；凭据只做必要脱敏。确定性 hard-block 在两种目标上始终生效，不能由审批覆盖。

## 后果

- 常规 Sandbox 工作不产生审批噪音；
- 每个宿主副作用都具有清晰的人类授权边界；
- 用户不能通过一次授权永久扩大 Agent 权限；
- 无人值守任务不能执行需要宿主审批的调用；
- 审批服务不可用、超时或结果不确定时必须失败关闭。

## 替代方案

完全禁止宿主执行会阻断 U 盘、部署诊断等必要工作；继续采用仅审计不审批的方式会让宿主边界缺少人类确认；会话级或永久授权容易被无关后续调用复用。以上方案均不采用。
